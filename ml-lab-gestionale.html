Importa da CSV

Trascina qui un file .csv, oppure clicca per selezionarlo
Riconosco due formati automaticamente. File piano check (colonne: Cliente, Check completati, Data prevista check, Data rinnovo, Stato, Tipo check previsto…): sostituisce l'intero elenco clienti. File CRM/pagamenti (colonne: Cliente, Pagamenti pacchetto, Pagato 1-5, Scadenza 1a-5a, Servizio…): aggiorna solo servizio, contatti e pacchetto pagamento dei clienti esistenti (per nome) e ne crea di nuovi se non li trova, senza toccare i check già pianificati.
Il piano check crea un solo check iniziale per cliente (quello indicato nel file); poi puoi far generare i successivi dalla cartella del cliente.
